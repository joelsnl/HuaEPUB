# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview
novelDownloader is a Python GUI application (CustomTkinter) for downloading Chinese web novels, optionally translating them to English via the free Google Translate endpoint, and packaging them as EPUB files.

## Layout
All application code lives at the repository root (there used to be a duplicate copy in `novel_downloader/`; it was removed - do not recreate it).

- `app.py` - GUI entry point (single and multi-download modes)
- `core/parser.py` - `BaseParser`, `Chapter`/`NovelInfo` dataclasses, parser registry, `create_http_session()` (curl_cffi Chrome impersonation with requests fallback)
- `core/cleaner.py` - `ContentCleaner`: watermark/ad removal, XHTML structure fixing, br-to-p conversion
- `core/translator.py` - `GoogleTranslator`: concurrent translation with bounded multi-pass retry (hard cap on passes; partial improvements are accepted so it never loops forever)
- `core/epub_builder.py` - `EPUBBuilder` and `TranslatedEPUBBuilder` (ebooklib); translations are applied at the text-node level, never with raw string replacement
- `core/updater.py` - auto-updater against GitHub releases
- `core/settings.py` - persistent app settings (JSON)
- `core/cache.py` - SQLite caches: downloaded chapters (resume support) and translations
- `parsers/` - one module per supported site (`twkan.py`, `shuba69.py`, `uukanshu.py`) plus `generic.py`, a heuristic fallback for unsupported sites. Registration order matters: `parsers/__init__.py` must import `generic` LAST so it only matches when no dedicated parser does.
- `tests/` - offline pytest suite with HTML fixtures (no network access needed)
- `build.py` / `NovelDownloader.spec` - PyInstaller packaging (the spec is generated by build.py)

## Workflow
Source Input → Parse → Clean → Translate (optional) → Build EPUB.

Chapter downloads are sequential on purpose (per-site `request_delay` avoids bans); do NOT parallelize them.

## Commands
- Run the app: `python3 app.py`
- Run tests: `python3 -m pytest tests/`
- Build executable: `python3 build.py`
- Dependencies: `pip install -r requirements.txt`

## Conventions
- To support a new site: add a parser in `parsers/`, register with `@register_parser`, import it in `parsers/__init__.py` before `generic`.
- Parsers must RAISE on failed content extraction (never return placeholder HTML); the app handles failures and retries them at the end of a run.
- Text cleaning rules live in `core/cleaner.py`; output format changes in `core/epub_builder.py`.
- Keep the default of 200 translation workers; the retry/backoff logic in `translator.py` handles rate limiting.
